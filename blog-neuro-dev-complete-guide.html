🚀 Neuro-Dev Kya Hai?

Neuro-Dev ek comprehensive ethical hacking platform hai jo specially mobile users ke liye design kiya gaya hai. Yahan aap Termux basics se lekar advanced penetration testing tak sab kuch seekh sakte hain Roman Urdu mein.

Mission: Har Pakistani student ko ethical hacking sikhana, chahe uske pass laptop ho ya na ho. Mobile se hi complete cybersecurity education provide karna.

📱 Mobile-First Approach Kyun?

Zyada tar students ke pass laptop nahi hai, lekin smartphone zaroor hai. Traditional cybersecurity courses laptop require karte hain, jo affordable nahi hai.

Problems Jo Hum Solve Karte Hain:

  • 💰 Cost Barrier: Laptop ki zaroorat nahi
  • 🌐 Language Barrier: Roman Urdu mein content
  • 📚 Complex Content: Step-by-step practical approach
  • ⏰ Time Constraint: Mobile pe kahi bhi seekh sakte hain

🎯 Platform Features

Mobile Optimized

Responsive design jo mobile pe perfect work karta hai. Touch-friendly interface aur fast loading.

Roman Urdu Content

Har command aur concept Roman Urdu mein explain kiya gaya hai. Local examples aur references.

Copy Commands

Har command ke saath copy button. Ek click mein command copy kar ke Termux mein paste karo.

Virtual Labs

Interactive virtual machine labs jo browser mein run hote hain. Real hacking environment.

CTF Challenges

49+ Capture The Flag challenges jo practical skills test karte hain. Gamified learning.

AI Assistant

AI-powered help system jo real-time doubts clear karta hai aur personalized guidance deta hai.

📚 Course Modules

Module 1: Termux Basics

Android pe Linux environment setup, basic commands, file operations, package management.

Module 2: Termux Advanced

Python scripting, Git usage, SSH access, automation scripts, storage permissions.

Module 3: NetHunter Rootless

Kali Linux tools installation without root, VNC setup, desktop environment configuration.

Module 4: NetHunter Tools

Nmap, Metasploit, Aircrack-ng, SQLmap, Burp Suite mobile, social engineering tools.

Module 5: Networking Course

Network fundamentals, IP addressing, port scanning, reconnaissance, vulnerability assessment.

Module 6: Web Application Security

OWASP Top 10, SQL injection, XSS, CSRF, web app reconnaissance, Burp Suite advanced.

Module 7: Mobile Security & OSINT

Android security testing, APK analysis, social media intelligence, Google dorking, digital footprint.
